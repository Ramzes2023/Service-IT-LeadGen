# ЕИС — целевой поиск услуг 1С после успешного отрицательного контроля

**Проверено пользователем 31 октября 2026:** Windows `149 passed in 1.58s`; `PIPELINE_EXIT=0`; официальный HTTPS/RSS доступен; первоначальная пробная выдача `searchString=1С&fz44=on` содержит 200 извещений, 181 не содержит 1С в предмете, 19 не имеют распознанного поля предмета; контроль по заведомо невозможной фразе дал 0 извещений. Это подтверждает влияние `searchString` на результат, но **не доказывает**, что условия поиска ограничены предметом закупки или нужным регионом.

## Добавленный этап

`leadpilot.eis_targeted_1c` использует **ту же уже подтверждённую официальную RSS-ссылку** и меняет только существующий `searchString`, не выдумывая параметров сайта. Последовательно, без повторов, четыре варианта:

1. сопровождение 1С;
2. техническая поддержка 1С;
3. доработка 1С;
4. настройка 1С.

**Четыре одиночных официальных HTTPS GET** с TLS-проверкой. На ошибке/429 выполнение останавливается; никаких логинов, токенов, скрытых данных, копирования личных контактов и обхода защиты.

По каждому варианту сохраняется оригинальный отчёт RSS с действительным URL извещения, названием закупки, датой, источником и отметкой `buyer_inn=null`. Между вариантами дубли по официальной ссылке удаляются в агрегированной сводке. Подтверждённые коммерческие лиды всегда = **0 до отдельной проверки**.

### Результат

`exports/eis_targeted_1c_<время>_{support,technical,customization,setup}.json` — четыре раздельных исследовательских отчёта, которые можно передать в `leadpilot.eis_buyer_review` после ручной верификации **конкретного покупателя** по первичному источнику.

`exports/eis_targeted_1c_<время>_summary.json` — сколько официальных извещений просмотрено, сколько прошли первичный 1С-фильтр, сколько уникальных исследовательских кандидатов. Полей или разрешения на запись в CRM нет.

### Windows

Скрипт `scripts/RUN_SERVICEIT_EIS_TARGETED_1C.ps1` запускает полный набор тестов (включая `tests/test_eis_targeted_1c.py`), читает уже полученный локальный JSON и выполняет ограниченный поиск. Исполнитель может использовать `-PythonPath` от существующего venv и независимую рабочую копию Git, чтобы не изменять `main`.

**Важно:** исходная ссылка всё ещё была пробной, с `fz44=on`. Результаты по 44-ФЗ, даже при наличии услуги 1С, скорее всего будут государственными и бюджетными заказчиками; нельзя записывать их как потребность микро/малых компаний Москвы/МО или считать автоматически релевантными «Сервис ИТ». При наличии реальных исследований закупки могут быть **возможностями участия «Сервис ИТ» в тендере**, отдельными от исходящих B2B-лидов.

Параллельные коммерческие закупки B2B-Center исследуются отдельно в PR #28; тот источник больше соответствует прямому B2B-спросу, но его API ещё не подключён и официальные права доступа не проверены. Для полноценной выборки Москвы/МО и 223-ФЗ нужно получить соответствующую RSS-ссылку после настройки фильтров в официальном интерфейсе и повторить проверки.

### Финальная готовность по Микаилу

Нужно дополнительно: подтверждённый предмет внешней услуги, активная процедура, реальный покупатель и **его ИНН**, размер компании по ФНС, Москва/МО, даты, корпоративный контакт и основание обращения, проверка существующих клиентов/дублей/стоп-листа, менеджерское решение, разрешённый тестовый Битрикс24. До этих условий `qualified_leads=0`, `crm_writes=NO`, `outbound_messages=NO`.
