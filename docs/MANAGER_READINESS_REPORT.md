# Единый офлайн-отчёт готовности кандидатов для менеджера

Цель — объединить **три уже сформированных локальных файла** первого пилота ООО «Сервис ИТ» (сопровождение 1С, Москва и МО) и показать руководителю, почему ни одна компания ещё не передана в Битрикс24.

## Входные файлы

- `exports/mvp_research_review.json` — 15 компаний-кандидатов, источник вакансии, Lead Score и AI-статус.
- `exports/mvp_enrichment_checklist.json` — сведения о малом бизнесе, официальном корпоративном контакте, датах и ручной проверке.
- `exports/mvp_scope_review.json` — решение о соответствии пилоту (пока все PENDING).

Данные хранятся только в локальной папке exports. **Перед запуском должны быть выполнены предыдущие команды подготовки**; переcоздавать файлы с ручными правками не нужно.

## Запуск PowerShell из корня репозитория

    .\.venv\Scripts\python.exe -m pytest -q
    .\.venv\Scripts\python.exe -m leadpilot.manager_readiness

Выход: `exports/mvp_manager_readiness.json`.

Отчёт содержит оценки, ссылки на источник сигнала, статус проверки целевого сегмента, статус доказательств и перечень следующего действия. Исходные личные контакты (телефон/email) намеренно не копируются.

## Жёсткие правила

- Соединение входных файлов **только по точному ИНН**; если наборы организаций не совпадают или один ИНН повторяется, работа останавливается.
- Независимой проверки официального реестра ФНС на все 15 компаний нет — заполненные вручную поля сами по себе не удостоверяют категорию предприятия.
- Результат всегда `crm_ready=0`. Наличие источника или высокого Lead Score не даёт права отправлять запись в Битрикс24.
- Известные компании и существующие лиды корпоративной CRM ещё не проверялись, а маркетинговые контакты не согласованы.
- Даже проверенная человеком неподходящая компания не попадает в глобальный стоп-лист CRM. Её только помечают как отложенную для первого пилота.
- Файл отчёта не перезаписывается: перед повторным запуском указать новое имя `--output exports/mvp_manager_readiness_v2.json` (не терять предыдущую версию).
- Нет обращений к интернету, AI, CRM и исходящих рассылок. VALYQON не является частью проекта.
