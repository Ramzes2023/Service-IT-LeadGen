# Состояние v0.3 — объективный статус приёмки

| Требование ТЗ | Статус |
|---|---|
| Подтверждённые компании/сигналы (источник + URL + дата) | В коде работает адаптер структурированных JSON; живое API-соединение **НЕ ПРОВЕРЕНО** |
| Москва/МО, Ингушетия | Поддерживаемые региональные фильтры 77/50/06; реальное API тестировать на компьютере |
| Источник 2 | Не подключён, требуется согласовать условия доступа (например, ЕИС) |
| ИНН и дедупликация | SQLite уникальный ИНН; без ИНН только staging, телефон/email не объединяют автоматически |
| Стоп-лист | Локальная схема и тесты; корпоративный Битрикс24 ещё не синхронизирован |
| GigaChat | Реальный HTTP адаптер + OAuth, проверены mocked HTTP-тесты; нет живого успешного ответа провайдера в текущей среде |
| Lead Score | Детерминированный расчёт, версия и составляющие, не LLM-генерация |
| Полноценная Bitrix CRM синхронизация | **НЕ ГОТОВА** — только JSON preview и чтение тестового портала по разрешённому вебхуку |
| Карточка задачи менеджеру в CRM | Ещё не создана в реальной CRM |
| Маркетинговые контакты / Билайн / боты | Не подключено; без согласия массовые коммуникации не выполняются |
| Полная воронка/KPI, финансовая мотивация | Не готово; демонстрационный расчет РВП, но нет подтверждений и аудита выплат |
| Валидация | 29 локальных тестов, включая MockTransport, НЕ end-to-end на реальных системах |

Документация основана на ТЗ «Сервис ИТ» v3.0 (15 страниц), без утверждения, что тестовое задание автоматически выполнено в полном объёме.
