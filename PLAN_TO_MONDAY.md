# Этапы проекта до демонстрации — 2 ноября 2026

1. Запуск приложения Windows PowerShell 5.1 через **уже установленный** `py -3.12`, демо-панель на `localhost:8766` и 29 локальных тестов.
2. Провести **живую read-only проверку** API «Работа России» на компьютере пользователя (Москва, Московская область): получить публичные вакансии, ссылки и даты; при наличии настоящего ИНН — импортировать в локальную research SQLite; без ИНН — staging. Никаких автоматических холодных контактов.
3. Проверить авторизованный GigaChat (только синтетические тексты); затем при явном разрешении анализировать названия **публичных** вакансий без названий компаний или контактов. Lead Score остаётся расчётом Python.
4. Получить тестовый Битрикс24 компании или зарегистрировать отдельный тестовый портал с нужными правами. Сначала выполнить `CRM_READONLY_CHECK.ps1`, затем только после дополнительного согласования реализовать тестовую запись лидов с полями и справочником сигналов.
5. Выдать руководителю архитектуру, результаты тестов, ограничения и план внедрения: второй источник (ЕИС), карточки/задачи в рабочем CRM, телефонная инфраструктура, боты, воронка продаж, финансовые права и отчёты.

**Важно:** полное ТЗ включает коммерческие интеграции и 4–6-недельный пилот. Версия v0.3 — не выполненная промышленная поставка. Реальный API и авторизация внешних провайдеров должны быть подтверждены отдельными испытаниями.
