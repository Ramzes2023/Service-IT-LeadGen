# Подключение RouterAI к новым карточкам Сервис ИТ

Сервис из сообщения WhatsApp: routerai.ru, базовый URL https://routerai.ru/api/v1. Ранее упомянутый DeepSeek является моделью через маршрутизатор, а не прямым адресом API.

Провайдер конфигурации: routerai. Модель: deepseek/deepseek-v4.1-flash. Адрес запросов: https://routerai.ru/api/v1/chat/completions. Резервный вариант: gigachat.

Ключ, отправленный на скриншоте WhatsApp, раскрыт — его необходимо отозвать в кабинете RouterAI и выпустить новый. Никогда не публиковать его в Issue, коммитах и чате.

Владелец GitHub один раз добавляет новый ключ в Settings > Secrets and variables > Actions: секрет SERVICEIT_ROUTERAI_API_KEY. После решения руководителя о разрешённой передаче корпоративных данных RouterAI: переменная SERVICEIT_ROUTERAI_PRIVACY_APPROVED со значением YES_1062_21. Затем переменная SERVICEIT_AI_PROVIDER = routerai.

Для возврата: SERVICEIT_AI_PROVIDER = gigachat. При отсутствии переменной выбирается GigaChat. Новая интеграция не меняет уже обработанные карточки, фактический Score, проверки ФНС и CRM-дублей, Kanban или текущую воронку техподдержки.

Без нового действительного ключа и отдельного разрешения реальный RouterAI API тест и переключение запрещены. Покупка ключа не равна разрешению передачи внутренних данных.

Базовый AI-режим отправляет ограниченный текст публичного заголовка только после проверки домена источника и разрешения. Для внутренних документов/CRM данных требуются корпоративные approvals. Модель возвращает гипотезу, цитату и направление услуги, а не подтверждённый лид или конечный Lead Score.

Справка: https://routerai.ru/docs/guides/overview/quickstart ; https://routerai.ru/models/deepseek/deepseek-v4.1-flash
