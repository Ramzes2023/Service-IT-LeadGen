# Михаилу: демонстрация B2B-сигналов ServiceIT

**SYNTHETIC PREVIEW. Только локальная модель, без реальных лидов и контактов.**

Готовая демонстрация: [открыть HTML](manager-demo-audited/index.html).
Подробный учебный след: [report.json](manager-demo-audited/report.json).
HTML не использует сеть, внешние ресурсы или JavaScript. Это не скриншот и не
имитация существующих карточек в корпоративном портале.

## Что показать за три минуты

1. Открыть HTML двойным щелчком. Обратить внимание на маркировку SYNTHETIC PREVIEW.
2. Показать два независимых учебных сигнала одной вымышленной компании из Москвы:
   запросы проекта 1С, ИНН, источник, URL доказательства, оценка и решение.
   example.invalid — адрес учебного доказательства, он не должен открываться.
   Учебный ИНН проходит контрольную сумму; это не утверждение о владельце ИНН.
3. Объяснить: повтор первого сигнала не создаёт вторую операцию; стоп-компания
   удерживается; действующие клиенты и ручная блокировка также исключаются.
4. Показать разные решения: релевантный сигнал и необходимость исследования.
   SUCCESS в этой модели означает решение по сигналу, **не продажу и не сделку**.
   Решение менеджера никогда не разрешает контакт с человеком.
5. Показать восстановление после потери ответа: только сверка mock list/get,
   без повторного POST. Локальный VERIFIED не доказывает наличие карточки в CRM.

Оценка 86/100 взята из учебной фикстуры и проверяется по диапазону и версии.
Это не обученная модель вероятности продажи и не доказанная квалификация компании.
Источники synthetic-fixture и synthetic-second независимы только в модели.
Вакансии не являются конечным продуктом этой демонстрации.

## Как сгенерировать заново на Windows

Из корня этого worktree:

```powershell
powershell -NoProfile -File scripts/RUN_SERVICEIT_BITRIX_MANAGER_DEMO.ps1
```

Нужен существующий Python 3.12 через `py`; внешние библиотеки для демо не нужны.
При необходимости можно передать `-PythonPath` с путём к существующему python.exe.
Скрипт печатает пути HTML и JSON. Новый каталог создаётся внутри `docs/` текущего
worktree; существующий каталог не перезаписывается. Не требуются вход в Bitrix24,
секреты, настройка источников или подключение к интернету.

Не создавать карточки и не менять права, поля или воронки ради этой демонстрации.
