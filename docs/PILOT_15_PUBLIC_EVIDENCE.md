# Исследовательская проверка первоначальных 15 ИНН — 31.10.2026

## Назначение
Начальный сбор 1С-вакансий дал 15 кандидатов. Первое письмо Микаила требует малых компаний Москвы/МО. Публичные источники показывают, что существенная часть работодателей — средние компании, большие предприятия, вузы или бюджетные организации. Нельзя считать эти 15 записей готовыми лидами.

Файл samples/mvp_15_public_research_hints.json содержит **только публичные сведения об организациях** и ссылки на источники; никаких личных телефонов, личных email или действующих CRM-записей. Подсказки нельзя считать подтверждением категории ФНС, согласием на рекламу, завершённой проверкой менеджера или разрешением на запись в CRM.

## Как получить локальный отчёт-подсказку на Windows

Из ветки feat/mvp-manager-readiness-20261031 (обновлённой через git pull --ff-only):

    .\.venv\Scripts\python.exe -m pytest -q
    .\.venv\Scripts\python.exe -m leadpilot.research_triage

Результат: exports/mvp_public_research_hints.json. Файлы exports/mvp_scope_review.json и exports/mvp_manager_readiness.json не изменяются и не перезаписываются. После одной успешной генерации повторный запуск с тем же именем результата остановится (защита истории), можно указать --output exports/mvp_public_research_hints_v2.json.

Ни один статус не является командой связаться с компанией, одобрить CRM-лид или исключить организацию автоматически. Для нужных двух кандидатов проверить категорию по ИНН на https://rmsp.nalog.ru/. Для санкционно отмеченной компании — юридический просмотр, до одобрения никаких коммерческих действий. Для всех — проверка работодателя, законно опубликованного корпоративного контакта, дублей CRM и реальной релевантности услуги.
