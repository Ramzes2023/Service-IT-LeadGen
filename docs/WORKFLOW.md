# Схема сохранения каждого этапа

1. Работать в отдельной папке `Service-IT-LeadGen`, никогда не менять `TenderLens-AI`.
2. Для каждого изменения добавить тест; запуск: `.\.venv\Scripts\python.exe -m pytest -q`.
3. После успешных тестов: `powershell -NoProfile -ExecutionPolicy Bypass -File .\SAVE_STEP.ps1 -Message "feat: описание этапа"`.
4. Скрипт сохраняет изменения коммитом и отправляет их только в `Ramzes2023/Service-IT-LeadGen` после проверки `origin`.
5. В GitHub хранить **код, тесты, документацию, шаблон .env.example**. Локальные `.env`, ключи, снимки компаний, `research.sqlite3`, CRM-данные и логи не загружать.
6. Перед изменениями CRM проводить отдельную проверку разрешений и тестового окружения.

Важно: Git commit/save в этой инструкции не значит автоматический бэкап данных и не запускается в фоне. Вызывайте после завершённого этапа.
