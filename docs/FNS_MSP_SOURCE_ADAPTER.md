## ФНС: источник подтверждения размера компании

Официальный набор: https://www.nalog.gov.ru/opendata/7707329152-rsmp/

Формат: XML внутри ZIP; в записи «Документ» указан КатСубМСП (1 = микро, 2 = малое, 3 = среднее), дата среза; ИНН хранится в ОргВклМСП/ИННЮЛ либо ИПВклМСП/ИННФЛ.

Архив очень большой; никаких автоматических скачиваний или публикации в GitHub. Тестируем потоковый локальный сопоставитель по 15 ИНН. Подтверждение МСП не является согласием на рекламу и не снимает необходимости проверки дублей в Битрикс24.

До проверки происхождения архива статус источника — LOCAL_FILE_AUTHENTICITY_UNVERIFIED. CRM_READY остаётся NO.


## Сверка с опубликованным паспортом ФНС — 31.10.2026

На официальной странице https://www.nalog.gov.ru/opendata/7707329152-rsmp/ опубликован текущий срез `data-10102026-structure-12052026.zip` (данные на 10.10.2026) и актуальная XSD `structure-12052026.xsd`. XML-формат 4.06; группа `Документ` содержит `ДатаСост` и `КатСубМСП`, категория 1 = микро, 2 = малое, 3 = среднее, а ИНН находится в `ОргВклМСП/ИННЮЛ` либо `ИПВклМСП/ИННФЛ`. Эти сведения подтверждены паспортом ФНС и вторичным разбором структуры, **но фактический прогон нашего кода на полном официальном ZIP не выполнен**.

### Экономичный порядок для пилота из 15 компаний

1. Взять 15 ИНН из локального `exports/mvp_enrichment_checklist.json`.
2. Проверить по каждому ИНН запись и категорию в официальном пользовательском реестре https://rmsp.nalog.ru/. Сохранять источник, **точную дату записи/среза**, категорию и дату просмотра; **не считать ссылку только на главную страницу доказательством для конкретного ИНН**.
3. Независимо проверить официальный корпоративный контакт и источник. Ни МСП-статус, ни вакансия не подтверждают согласие на маркетинговые сообщения и реальную потребность купить 1С.
4. После получения разрешённого доступа Битрикс24 проверить дубли существующих компаний/контактов только чтением. До этого `crm_ready=0`.
5. Для массовой проверки большого потока организаций использовать разработанный локальный потоковый ZIP-модуль. Скачивать многогигабайтный архив только при необходимости, с учётом дискового места, условий источника, размера и контрольной проверки происхождения файла.

### Статус совместимости

- Подтверждено по документации: структура ZIP/имя среза, версия 4.06, атрибуты ИНН, даты и категории.
- Подтверждено тестами: разбор небольших синтетических ZIP и безопасное сопоставление по ИНН.
- **Не подтверждено:** полноценное исполнение на архиве ФНС за 10.10.2026; действительная МСП-категория всех 15 компаний; стоимость/скорость промышленной обработки; официальная аутентичность локальных копий ZIP.
- Не пытаться получать реальные контакты из XML МСП: это не реестр разрешений на коммуникации.
