# Подключение первого источника к рабочему порталу Микаила: безопасный этап 0

**31.10.2026 — подтверждено входящее письмо «Приглашение в Битрикс24»** от `no-reply@serviseit.bitrix24.ru` на адрес владельца проекта. Приглашение означает возможность вступить в команду, **не** выданный REST-токен и **не** одобрение записи в рабочую CRM. Секретный URL приглашения в GitHub не сохраняется.

## Запуск после принятия приглашения администратором/пользователем

1. Присоединиться к `serviseit.bitrix24.ru` из личного письма.
2. Администратор создаёт отдельный изолированный смарт-процесс точно `LeadGen AI — Тестирование` с ограниченными правами, без автоматических коммуникаций/роботов. **Не создавайте Lead в рабочей CRM для первого теста.** Воронка сделок НЕ изолирует обычные Leads.
3. Администратор разрешает только читающий входящий REST-вебхук с scope `crm` пользователя с ограниченными правами. Вебхук остаётся в локальной переменной `BITRIX24_TEST_WEBHOOK`; его нельзя отправлять по почте, в чат, лог или GitHub.
4. Из корня проекта, с установленной `.venv`, выполняется:
   ```powershell
   .\.venv\Scripts\python.exe -m leadpilot.bitrix_first_source_preflight
   ```
   Команда **только** вызывает `crm.type.list`, `crm.category.list`, `crm.item.fields` в **точном портале serviseit.bitrix24.ru** и сверяет название отдельного смарт-процесса. Не читает существующих клиентов, контактов, Leads или сделок, ничего не пишет.

## Критерии перехода к следующему этапу

- Активированный пользователь и права REST — фактически подтверждены ответом портала, а не наличием письма.
- `ISOLATED_READ_ACCESS_CONFIRMED` означает лишь видимость изолированного смарт-процесса, **не** разрешение вносить записи.
- Согласована форма карточки, проверка существующих клиентов/дублей и отдельное разрешение на одну **синтетическую** тестовую запись.
- Первый источник «Работа России» даёт реальные вакансии, но **не подтверждённые заявки на внешние услуги**. Реальная карточка требует актуальную ФНС, источник, законный канал, оценку, проверку дублей и решение менеджера.
- До всех проверок: `qualified_real_leads=0`, `crm_writes=NO`, `outbound_messages=NO`. Ни один синтетический тест не является реальным лидом.

Официальные инструкции Битрикс24: https://helpdesk.bitrix24.ru/open/20886106/ (вебхуки), https://helpdesk.bitrix24.ru/open/18913884 (смарт-процессы), https://apidocs.bitrix24.ru/api-reference/crm/universal/user-defined-object-types/index (REST).
